## 🌟 Key Features

* **✨ AI Financial Advisor:** Automatically analyzes income vs. expense ratios and generates instant smart budgeting insights and warnings.
* **📊 Comprehensive Dashboard:** Real-time calculation of Net Balance, Total Income, and Total Expenses.
* **📈 Visual Progress Ratio Bar:** Interactive ratio bar visualizing the precise balance between cash inflows and outflows.
* **🏷️ Category-Wise Spending Breakdown:** Live summary cards tracking expenses across categories (*Food & Drinks, Bills, Transport, Shopping, etc.*) with percentage distribution.
* **📥 Professional CSV Export:** One-click data export generating cleanly formatted financial spreadsheet reports.
* **🔒 Data Persistence:** Secure client-side data storage using browser `LocalStorage`.
* **🌙 Dark / Light Mode Support:** Fully responsive modern UI built with custom CSS variables for seamless theme switching.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox & Grid), Modern JavaScript (ES6+)
* **Storage:** Browser LocalStorage API
* **Design Philosophy:** Clean, Minimalist Enterprise Financial UI/UX
